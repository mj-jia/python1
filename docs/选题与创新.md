## 一、选题

**主标题**

> **面向图像传输退化的 Real-ESRGAN 复原方法改进**
> ——内容依赖退化建模与压缩伪影感知损失

**备选**

- 《传输压缩图像的盲复原：非均匀退化建模与块效应约束》
- 《从均匀退化到内容依赖退化：面向端侧传图的图像复原改进》

**范围声明（写进第一章，别含糊）**

- 对象：**静态图片**（JPEG / DCT 路径），不含视频帧。原因：H.264 的宏块级 QP 自适应是编码器显式行为，表述方式不同，混在一起会两套逻辑打架。
- 任务：**同分辨率复原**（scale=1），不是超分。题目是"糊了要变清晰"，不是"小了要变大"。
- 主干：Real-ESRGAN 的轻量骨干 SRVGGNetCompact，**结构不改**。

---

## 二、一句话定位

> 不是"我用 Real-ESRGAN 做图片复原"，而是
> **"我把 Real-ESRGAN 的通用随机退化替换成传输链路的真实退化，并针对传输特有的块状伪影与区域矛盾重设损失。"**

这句话是全篇的立论。它同时回答了"主干是开源的"这一质疑：主干开源不代表问题被解决，**退化定义与损失目标才是这个场景下真正要改的东西**。

---

## 三、问题：糊是怎么来的

真实传图链路（以"微信发非原图"为代表）有四个环节，每个环节的退化形态不同：

| 环节 | 物理过程 | 产生的伪影 |
|---|---|---|
| ① 编码压缩 | 8×8 DCT + 量化 + 色度 4:2:0 | 块效应、色带、蚊式噪声 |
| ② 降分辨率 | 长边缩到约 1080 档 | 高频整体丢失 |
| ③ 显示端插值放大 | 双线性 / 双三次上采样 | **糊的主因**，边缘发虚 |
| ④ 二次转码 | 再次量化 | 伪影叠加、色度偏移 |

**其中有一条容易被写错、必须写对的事实：**

编码器的量化误差**不是按区域均匀分配的**——率失真优化下，纹理区分到更多比特、量化步长更小；平坦区分到更少比特、量化步长更大。但**视觉上最刺眼的反而是平坦区**，因为平坦区缺少内容掩蔽，8×8 块边界和色带直接暴露。

> 即：**压缩强度在纹理区更大，伪影可见度在平坦区更高。这是两件事，不能混着说。**

这条区分是本项目的技术原点，也是答辩时最容易被追问的地方。第 5 节给出了实测数字来支撑它。

## 四、现有方法的三个不匹配

Real-ESRGAN 的退化是二阶随机采样：模糊 → 缩放 → 噪声 → JPEG，每步参数独立随机，目标是覆盖尽可能广的真实退化。

| 维度 | Real-ESRGAN | 传输链路 |
|---|---|---|
| 参数来源 | 随机采样 | 由码率预算决定，只有离散几档 |
| 空间分布 | 全局均匀 | **内容依赖**：平坦区与纹理区差异显著 |
| 损伤形态 | 只有平滑退化 | 还有**周期性块状伪影**，不是随机纹理 |
| 优化目标 | 全图统一偏向感知 | 平坦区要保真、纹理区要观感，**两者冲突** |

前两行催生创新一，第三行催生创新二，第四行催生创新三。**三处不匹配与三个创新点是一一对应的**，这个对应关系要在开题时讲清楚。

## 五、三个创新点

### 创新一 内容依赖的非均匀退化建模（数据侧）

**问题**：全图统一 JPEG 质量，把"比特分配与内容强相关"这一结构性规律抹平了，模型学到的是错误的退化先验。

**做法**：不用 libjpeg（它的 `quality` 是图像级参数，DQT 表全局唯一，做不到逐块量化），改用纯 numpy 自走一遍 DCT：

```
8×8 分块 → 算每块局部纹理能量 E → 按 E 分配量化步长 Q
→ DCT → 量化 → 反量化 → IDCT → 拼回 → 叠加降分辨率与插值放大
```

方向：**E 大 → Q 小（保细节）；E 小 → Q 大（省比特）**。写反了整个创新就失效。

**它为什么算创新而不只是"换了个数据生成器"**（这是必须准备的一问）：

1. 图像复原里，**技术贡献有相当部分来自退化定义**。用随机均匀退化训练，学的是通用盲复原；用链路退化训练，学的是传输退化专用的逆映射。网络结构完全相同，输入分布不同，学到的东西就不同。
2. 退化被**参数化**之后，每个因素可以单独开关，于是能做"关掉块效应损伤，PSNR 掉多少"这类消融，**用实验证明"传输特有退化必须建模"**。没有参数化，你只能说自己效果好，说不清好在哪。
3. 它产出可核对的定量证据（见下方实测），不是主观判断。

**已跑通的验证数字**（`python tools/verify_nonuniform.py` 实测，可直接进报告）：

测试条件：DIV2K `0009.png`，2 倍整数下采样、二次转码 q=66、放大后块间距 16px。

| 区域 | 块数 | 分配到的 quality | 块效应强度 | 块误差 MSE |
|---|---|---|---|---|
| 平坦区（低能量 30%） | 3553 | 46.8 | **1.253** | 10.68 |
| 纹理区（高能量 30%） | 3553 | 75.3 | 0.926 | **483.81** |
| 全图 | 11844 | 62.6 | 1.250 | 195.00 |

- 平坦区块效应是纹理区的 **1.35 倍**，纹理区块误差是平坦区的 **45.3 倍**。
- 逐块 quality 与局部能量的相关系数 **r = 0.960**（强正相关，说明分配真的按内容走）。
- 与「全图统一 quality」对照：非均匀把平坦/纹理块效应比拉开到 1.35，均匀分配只有 1.05。

> 这里必须把一个定义写清楚：块效应强度 = 块边界梯度均值 /（块内梯度均值 + 0.5 灰度级）。
> 分母加底噪是因为平坦区内部梯度趋近 0，不设下限会让比值发散到无意义的量级。

**成本**：已实现并跑通，只碰数据脚本。**交付**：`src/degrade/dct_degrade.py` + `experiments/verify/` 下的可视化图（红色=压得狠）。

### 创新二 压缩块效应感知损失（损失侧）

**问题**：8×8 块效应是**严格周期的结构伪影**，与自然纹理的统计分布完全不同。GAN 的通用判别器对这种规律不敏感，训练后仍会残留规则方块——这是传输场景下最不像照片的伪影。

**做法**：不加网络分支（块效应是输出的可直接度量属性，不需要专门网络去"识别"它），直接算经典度量：

```
blockiness(x) = 块边界梯度均值 / (块内梯度均值 + 0.5/255)
L_block = relu( blockiness(output) − blockiness(GT) ) / clamp(blockiness(GT), 0.3)
```

三个实现细节：
- **分母底噪**：平坦区内部梯度趋近 0，不设下限比值会发散，加半个灰度级作保护。
- **block 尺寸**：退化图上的块被放大了，`block = 8 × 下采样倍数`（2 倍时是 16），
  用 8 去量会量错位置。
- **除以 GT 水平**：让损失变成无量纲相对量，才能和 L1 按合理比例配权重。

`relu` 的作用是**单向惩罚**：只在"输出比 GT 更像块状"时罚，避免把正常边缘一起压掉。

**为什么用解析度量而不是再加一个判别器**：零新增参数、无训练不稳定风险、可直接画成曲线进报告，而且"我测得出这个量"比"我训了个网络来感觉这个量"更可验证。

**成本**：约 1 天。**交付**：`src/train/losses.py::BlockinessLoss`。

> ⚠️ 不要顺口说"顺带缓解幻觉"。块效应损失对编造纹理的作用很弱，过度承诺会在追问时塌掉。

### 创新三 空间自适应的混合损失（损失侧）

**问题**：全图一套权重，但两类区域的需求是**互斥**的：

| 区域 | 首要目标 | 权重用错的后果 |
|---|---|---|
| 平坦区（天空、墙面、皮肤） | 数值准确、无色带、无块 | 用感知损失 → 涂出虚假纹理 |
| 纹理区（草地、树叶、织物） | 观感自然、细节不抹平 | 用纯 L1 → 塑料感、细节糊 |

这正是 Real-ESRGAN"PSNR 偏低、幻觉偏重"的**结构性原因**：它的目标函数在全图统一偏向感知质量。

**做法**：用局部梯度能量生成空间权重图，逐像素加权：

```
L = w ⊙ L1 + (1 − w) ⊙ LPIPS_spatial
```

- `w` 大（平坦区）→ 偏 L1 保数值
- `w` 小（纹理区）→ 偏 LPIPS 保观感
- 平坦区再叠加创新二的块效应项

**三个实现要点**（都踩过，别再踩）：

1. LPIPS 默认只输出全局标量，必须 `spatial=True` 才有空间图。
2. "动态加权"指**空间**加权，不是训练中自适应调整权重系数（那是 uncertainty weighting，另一回事）。说混了会被追问。
3. L1 与 LPIPS 尺度不同，加权前必须归一化，否则某一项会直接支配。
4. 平坦区不要纯 L1：L1 的最优解偏中值，会加重平滑感。用 `L1 + 块效应项`。

**成本**：约 1~2 天。**交付**：`src/train/losses.py::SpatialAdaptiveLoss`。

## 六、三点为什么是一条链，不是三个亮点

```
创新一（数据）造出「带周期性块效应的非均匀退化」
      ↓  提供针对性
创新二（损失）专门压制其中最难缠的「8×8 规则方块」
      ↓  清掉方块后
创新三（损失）才能按区域决定「保数值还是保观感」
```

缺一环就断：没有一，二的损失项无事可做（退化里本来就没多少块效应）；没有二，三的平坦区仍会残留方块，加权也救不回来。

**三点的共同定位**：全部作用在**数据侧与损失侧**，主干网络、推理流程、部署方式一律不动。这是"低风险且讲得清"的根本保证，也是"工作量可控"的来源。

| | 官方 `realesr-general-x4v3` | 本项目 |
|---|---|---|

一句话：**不是换了个更大的模型，而是让同一个模型看见对的问题、优化对的目标。**

## 八、实验设计（四组消融，同 seed 同迭代）

| 组 | 训练退化 | L1 | 块效应损失 | 空间加权 | 回答什么问题 |
|---|---|---|---|---|---|
| A 基线 | 非均匀 | 普通 | ✗ | ✗ | 只用退化建模的收益 |
| B | 非均匀 | 普通 | ✓ | ✗ | 创新二单独贡献 |
| C | 非均匀 | 空间自适应 | ✗ | ✓ | 创新三单独贡献 |
| D 完整 | 非均匀 | 空间自适应 | ✓ | ✓ | 合起来多少 |

**指标**：PSNR / SSIM（保真）+ LPIPS（观感）+ **分区局部指标**（平坦区块效应、纹理区梯度能量）+ 块效应强度。

**评测口径**：512×512 center crop，测试集单独划分，报告里写明。

**为什么必须有分区指标**：整体 PSNR 提升通常只有 0.3~0.8 dB，单看这个数字说服力有限。分区指标才能说明"收益确实来自空间自适应"，而不是"整体变好一点"。

## 九、结论（已实测，可直接用）

全部实测（DIV2K_valid 后 80 张，512 center crop，固定退化 seed）：

| 组 | 训练 | PSNR↑ | SSIM↑ | LPIPS↓ | 块效应↓ | 平坦区 Δ块效应↓ | 纹理梯度保留↑ |
|---|---|---|---|---|---|---|---|
| 退化图（不处理） | - | 26.258 | 0.7573 | 0.3678 | 1.077 | - | 1.000 |
| A 只用退化建模 | 从零 6k | 27.280 | 0.7892 | 0.2818 | 0.981 | +0.108 | 0.494 |
| B +块效应损失 | 从零 6k | 26.822 | 0.7744 | 0.3105 | **0.819** | **-0.140** | 0.456 |
| C +空间加权 | 从零 6k | 26.824 | 0.7724 | 0.1743 | 1.019 | +0.094 | **0.527** |
| D 完整 | 从零 6k | 26.802 | 0.7711 | 0.1746 | 0.874 | -0.094 | 0.516 |
| **G 最终模型** | **官方权重微调 3k** | **27.389** | **0.7909** | **0.1644** | 0.890 | -0.075 | **0.538** |

**最终交付模型 = G**（加载 `realesr-general-x4v3` 的 32 层 body + 重训输出层 + 3000 iter 微调）。
相对从零训练的 A 组：PSNR **+0.109**、SSIM **+0.0017**、LPIPS **−0.117**、块效应 **−0.092**，
**没有任何一个指标变差**（帕累托改进）。

**摘要末段可用这一句**：

> 本文不改动 Real-ESRGAN 主干结构，仅从退化建模与损失设计两侧进行传输场景适配：构建内容依赖的非均匀压缩退化流水线，引入可微的块效应感知损失抑制规律性方块伪影，并以空间自适应权重平衡平坦区保真度与纹理区感知质量。在推理开销与官方权重完全一致的前提下，最终模型在测试集上取得 **+1.13 dB** 的 PSNR 增益、**LPIPS 从 0.368 降至 0.164（−55%）**、全局块效应 **从 1.077 降至 0.890（−17%）**，且平坦区块效应由"高于 GT 0.075"以上水平转为低于 GT。

**四组从零训练的消融揭示了三种不同的取舍，这是方法论证的核心**：

- **A 是保真极值**：PSNR 27.280 最高，但 LPIPS 最差、块效应几乎没改善（0.981 vs GT 0.919）。
- **B 是块效应极值**：块效应压到 0.819（已低于 GT），但纹理梯度保留掉到 0.456——**为了压方块把细节一起抹了**，说明单靠块效应损失会误伤纹理区。
- **C 是感知极值**：LPIPS 最好（0.174）、纹理保留最好（0.527），但块效应反而升到 1.019。
- **D 是均衡解**：块效应 0.874、LPIPS 0.175，两个维度都接近各自最优，代价是 PSNR 让出 0.478 dB。

**"B 误伤纹理 → D 用空间加权把它救回来"这一步，就是三点成链的直接证据**。

**必须诚实写进局限的一条**：G 的提升主要来自官方预训练权重（它见过海量真实退化），
三个创新点本身的贡献被这个强起点部分掩盖。要单独量化创新的增量，
需要一个"官方权重 + 纯 L1"的对照实验（尚未跑）。

## 十一、必须准备的五问

1. **"主干是开源的，你做了什么？"**
   → 退化定义、损失目标、分区权衡三处改造；结构不动是刻意选择，为的是让增益可归因。

2. **"PSNR 只提升 0.5 dB 有什么意义？"**
   → 给三个数：LPIPS 降 52%、块效应降 19%、平坦区块效应由 +0.108 转为 -0.094。
   → 再加一句"这 0.478 dB 的 PSNR 让步换来的是 0.107 的 LPIPS 改善"，把交换关系摆明。

3. **"你的仿真凭什么代表真实传输？"**
   → 已有部分答案（`experiments/verify/report.md` 表 4）：
      真实 libjpeg 的块效应同样集中在平坦区（比值 1.08~1.14），方向与本方案（1.35）一致，
      差距来自 baseline JPEG 没有块级 AQ。
   → **仍缺的**：20 对真实微信传输图做端到端验证。这一项没做，答辩前必须补，
      否则"仿真是否代表真实"只能靠间接证据。

4. **"为什么不直接把模型做大？"**
   → 端侧复原是场景前提（服务端复原要多传一次，带宽反而更贵），所以成本必须可控。这是"算过账"不是"跑不动"。

5. **"创新一是不是只是造数据？"**
   → 用第五节的 4.5 倍 / 8 倍那组数字回答：退化分配是可测的物理事实，不是主观设定；而且参数化后可做开关消融。
